# TUI 状态：

| 状态           | 显示                  | 颜色                                  |
| -------------- | --------------------- | ------------------------------------- |
| 正在连接       | `⧉ ...`               | dim                                   |
| 已连接无选区   | `⧉ ✓`                 | dim                                   |
| 连接错误       | `⧉ ✕`                 | `⧉` 是 `dim` 颜色,`✕` 是 `error` 颜色 |
| 待发送 pending | `⧉ ⇡ src/foo.ts#L1,2` | success                               |
| 已发送 sent    | `⧉ ✓ src/foo.ts#L1,2` | dim                                   |
